## Introduction

This repository contains practical implementations and experiments in Computer Vision:
- Fine-tuning and transfer learning using modern CNN architectures (ResNet-50, VGG-19, EfficientNet-B0, Xception) for image classification.
- Video action recognition using custom 3D CNN architectures on the UCF50 dataset.

## Environment Setup

### Prerequisites

- Python >= 3.8
- CUDA-compatible GPU (recommended)

### Installation

1. Clone the repository:

```bash
git clone git@github.com:ntrThanh/Advanced-Reading-On-Computer-Vision.git
cd Advanced-Reading-On-Computer-Vision
```

2. Create and activate a virtual environment:

```bash
python -m venv venv
source venv/bin/activate
```

3. Install dependencies from requirements.txt:

```bash
pip install -r requirements.txt
```
